RequirementsXAMPP (Provides Apache + PHP + MySQL bundle) — Compatible with Windows, macOS, and Linux.2. Project InstallationCopy the entire quiz-system project folder into your XAMPP htdocs directory:Windows: C:\xampp\htdocs\quiz-systemmacOS: /Applications/XAMPP/htdocs/quiz-systemLinux: /opt/lampp/htdocs/quiz-system3. Database Initialization (Single Step)Open the XAMPP Control Panel and start the Apache and MySQL modules.Open your web browser and go to http://localhost/phpmyadmin.Click on the Import tab in the top menu.Select the sql/database.sql file from the project directory and click Go.This process creates the quiz_system database and all required tables (users, question_sets, questions, results, result_answers, question_reports, monthly_quizzes, monthly_questions, monthly_attempts), sets up the default administrator account, and inserts 15 question sets comprising 225 questions on "Web and Internet" topics.4. Database Connection ConfigurationVerify that the database parameters inside config/db.php match your local MySQL configuration (default XAMPP parameters work out of the box):$DB_HOST = "localhost";
$DB_USER = "root";
$DB_PASS = "";
$DB_NAME = "quiz_system";

http://localhost/quiz-system/index.php🎯 Key Application FeaturesDynamic Set Assignment by Student IDUpon user registration, each student is automatically assigned a specific question set based on their generated user_id:assigned_set_number = ((user_id - 1) % 15) + 1
This algorithm ensures that students receive varied question sets. The implementation can be found in the get_assigned_set_number() function within includes/auth.php.Question Structure per SetEach set contains 15 questions (10 Multiple Choice Questions + 5 True/False questions) tailored for university-level Web & Internet curriculum.Enforced 15-Minute Countdown TimerThe exam start time is recorded in server-side session variables ($_SESSION) when attempt_quiz.php loads.A client-side live countdown timer (15:00) is managed via js/validate.js and inline JavaScript.Upon timer expiry, the form locks automatically and redirects to time_up.php ("Time Expired — Unsubmitted"); no attempt data is written to the database.Server-side elapsed time checks are enforced in submit_quiz.php to prevent submission bypasses via client-side script manipulation.Optional Unattempted Set SelectionAfter completing an assigned set, students can opt to attempt additional unattempted sets via choose_set.php from prompts in quizzes.php and results.php.Perfect Score Celebration (15/15)Achieving a 15/15 score triggers a celebration screen (celebration.php) featuring confetti UI elements and automatic playback of media from assets/videos/.Administrators can upload new media files (.mp4, .webm, .ogg up to 50MB) via Admin Panel → Manage Celebration Videos (admin/manage_videos.php). Media selection is randomized at runtime without requiring code modifications.Public & Anonymized LeaderboardsIndividual set results can be viewed on public leaderboards (leaderboard.php?set_id=...). The view displays score metrics, dates, and completion timestamps without exposing individual student identifiers. 🆕 Advanced Features1. Detailed Exam Reports & PDF GenerationView granular score breakdowns by selecting View on results.php or quizzes.php to access result_report.php.Generate standalone PDF reports via download_report.php powered by includes/simple_pdf.php (no external dependency requirements).2. Question Doubt ReportingStudents can log doubts on specific question items directly from their report screen.Submitted reports are routed to the question_reports table and managed by administrators via admin/question_reports.php.3. Scheduled Monthly Live QuizzesAdministrators can schedule timed live quizzes with fixed execution windows through admin/manage_monthly.php.Questions can be constructed manually or cloned from existing problem sets via admin/monthly_questions.php.Students participate synchronously via monthly.php. Late entries are bounded by MONTHLY_JOIN_GRACE_SECONDS.Winners are calculated by highest score, with execution time serving as a tiebreaker on monthly_leaderboard.php.🕒 System Timezone SettingsThe default execution timezone is configured to Asia/Dhaka in config/db.php for both PHP runtime environment and MySQL database sessions.
